# Data

`raw/` holds source data as acquired where licensing and repository size make that appropriate. `derived/` holds transformed datasets produced by VECA research.

Every substantive dataset must remain traceable to `research/source_register.md`. Derived data should document source IDs, transformations, dates, units, coordinate reference systems where relevant, and known limitations.

Do not commit large datasets merely to fill the repository. Storage strategy will be chosen when real source sizes and licences are known.
